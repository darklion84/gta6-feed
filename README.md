# GTA6 NEWS: лента коротких роликов

Автоматический агрегатор коротких роликов из GTA 6. Ничего не скачивает и не
перезаливает: хранит только ссылки и показывает ролики через официальные плееры
площадок.

- каждые 30 минут ищет свежие и популярные YouTube Shorts (до 90 секунд);
- принимает ссылки на TikTok и Instagram Reels, которые вы присылаете боту;
- отсекает дубли и перезаливы за последние 72 часа;
- присылает кандидатов вам в личку бота с кнопками «В канал» / «Пропустить»;
- одобренное постит в Telegram-канал и на сайт (GitHub Pages).

## Модерация

Чтобы бот мог вам писать, откройте его и нажмите **Start**. Сборщик
запускается раз в 10 минут, поэтому кандидаты приходят пачками, а после
нажатия кнопки пост выходит при ближайшем запуске (обычно до 10–15 минут).
Нажатие ничего не показывает сразу: при следующем запуске кнопки под
сообщением сменятся на «Опубликован в канале» или «Пропущен».

Пока 10 кандидатов ждут ответа, новые не присылаются. Без ответа за 12 часов
кандидат снимается. Ссылки, которые вы прислали сами, идут в канал без
модерации. Выключить модерацию: `MODERATION = False` в `config.py` (и поднимите
пороги, как там написано).

Сервер не нужен: всё работает на бесплатных GitHub Actions и GitHub Pages.

## Запуск (минут 20)

1. **Telegram.** Создайте канал. В @BotFather создайте бота и сохраните токен.
   Добавьте бота в канал администратором с правом публикации. Свой числовой ID
   узнайте у @userinfobot.
2. **YouTube.** В Google Cloud Console создайте проект, включите
   «YouTube Data API v3», создайте API key.
3. **GitHub.** Создайте **публичный** репозиторий и загрузите в него все файлы
   из архива (включая папку `.github`).
4. **Секреты.** Settings → Secrets and variables → Actions → New repository secret:

   | Имя | Значение |
   |---|---|
   | `YOUTUBE_API_KEY` | ключ из шага 2 |
   | `TELEGRAM_BOT_TOKEN` | токен бота |
   | `TELEGRAM_ADMIN_IDS` | ваш числовой ID (несколько через запятую) |

5. **Сайт.** Settings → Pages → Source: **GitHub Actions**.
6. **Адреса.** В `config.py` впишите `SITE_URL` (адрес Pages со слэшем в конце),
   `TELEGRAM_URL` и `TELEGRAM_CHANNEL` (`@имя_канала`).
7. **Первый запуск.** Actions → feed → Run workflow. Дальше оно работает само.

Любой секрет можно не задавать: без ключа YouTube пропускается поиск, без
токена бота ролики идут только на сайт.

## TikTok и Instagram

У этих сетей нет официального поиска для таких проектов, поэтому ролики
добавляются вручную: пришлите боту в личку ссылку, после неё можно дописать
подпись.

```
https://www.tiktok.com/@author/video/7300000000000000000 Cop chase gone wrong
```

Бот ответит, что ролик в очереди, и он выйдет при ближайшем запуске. Бот
слушает только ID из `TELEGRAM_ADMIN_IDS`, остальным даже не отвечает.
Запасной способ: строка в `links.txt`.

Понимает ссылки YouTube, TikTok, Instagram и на посты публичных
Telegram-каналов (`https://t.me/channel/123`).

### Пересылка постов боту

Можно просто переслать боту пост из Telegram:

- если в посте есть ссылка на YouTube, TikTok или Instagram (в том числе
  спрятанная под словом), в ленту пойдёт она;
- если это видео из публичного канала, бот перешлёт его в ваш канал штатной
  пересылкой Telegram (с пометкой «переслано из …»), а на сайте пост
  встроится виджетом Telegram;
- если источник закрытый (приватный канал, личный чат), пост выйдет только
  в канале: встроить его на сайт нельзя.

Сам бот видео не скачивает и не перезаливает.

## Настройка

Всё в `config.py`, с комментариями. Главное:

- `QUERIES`, `MUST_MATCH`, `STOP_WORDS`: что искать и что отбрасывать;
- `POPULAR_MIN_VIEWS`, `FRESH_*`: пороги «уже популярный» и «свежий, быстро растёт».
  В первые дни после релиза просмотры огромные; если постов слишком много,
  поднимайте пороги, если мало, опускайте;
- `MAX_POSTS_PER_RUN`, `MAX_PER_CHANNEL_PER_DAY`: частота постов;
- `SEARCH_LANGUAGE`: какой язык поиск ставит выше (по умолчанию английский).

## Как устроено

```
feed/__main__.py   один проход: ссылки -> поиск -> статистика -> публикация -> feed.json
feed/youtube.py    YouTube Data API
feed/telegram.py   посты в канал и приём ссылок
feed/dedup.py      дубли: длительность ±1 с плюс похожее название или обложка
docs/index.html    сайт, читает docs/feed.json
data/db.json       база (создаётся сама, хранит 14 дней)
```

Локальный запуск: `pip install -r requirements.txt`, задать переменные окружения
из шага 4, затем `python -m feed`. Тесты: `python -m unittest tests.test_offline`.

## Что стоит знать

- **Квота YouTube.** По умолчанию 100 поисков в сутки, сборщик тратит до 95.
  Если нужно больше, квоту можно запросить у Google.
- **Расписание GitHub** неточное: запуск может задержаться на 5–20 минут.
- **Свой домен** подключается в Settings → Pages → Custom domain.
- **Версии actions** в `.github/workflows/feed.yml` стоит поднять, если GitHub
  покажет предупреждение об устаревании.
- **Правила площадок.** Проект не связан с Rockstar Games и Take-Two. Не
  используйте их логотипы и арт. Перед включением рекламы прочитайте условия
  YouTube API и встраивания TikTok и Instagram.
